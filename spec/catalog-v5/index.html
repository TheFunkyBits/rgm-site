Identity

The signed index declares a globally unique catalog version, compatibility floor, and sorted content-addressed file inventory. The detached envelope signs the exact index bytes. An app binding pins the immutable site URL, version, key ID, index hash, and envelope hash.

Verification

A client verifies the exact index and envelope hashes, one pinned Ed25519 signature, every declared object size and SHA-256, and the complete inventory before activating the release atomically.
